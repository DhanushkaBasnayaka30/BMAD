- (direction) User selected Coaching Path for FixNear Phase 1 architecture spine.
- (decision) AD: Next.js App Router + TypeScript full-stack monolith. Binds all routes, Prevents multi-repo/multi-service divergence.
- (decision) AD: Supabase managed backend (Postgres, Auth, Storage). Binds data persistence and user sessions. Prevents custom auth/storage infrastructure sprawl.
- (decision) AD: Provider onboarding uses Next.js Server Action with Supabase admin.createUser({ phone_confirm: true }) to allow phone+password registration without SMS gateway costs; login uses signInWithPassword({ phone, password }); Admin logs in via email+password.
- (decision) AD: Public directory reads query Supabase directly or via Next.js Server Components with Anon key. Postgres RLS enforces status = 'approved' for anon users. Admin routes bypass RLS using Server Actions with service_role key.
- (decision) AD: App Router directory split into (public), (provider), and (admin) route groups to prevent git collisions and allow independent development by 2 developers or subagents.
- (constraint) Service role key must strictly remain server-only (lib/supabase/admin.ts); never exposed to browser via NEXT_PUBLIC_, never committed to git.
- (direction) Spike: Conduct Phone Auth Spike before provider implementation to verify admin.createUser({ phone_confirm: true }) + signInWithPassword({ phone, password }) on live Supabase project; fallback is synthetic internal email identifier e.g. phone@fixnear.invalid (reserved RFC 2606 .invalid domain; email sending disabled in Supabase Auth).
- (decision) AD: RLS column protection and state transition enforcement. Public read policy strictly projects public columns via public_providers view. Provider UPDATE policy prevents mutating status, is_verified, or admin fields. Changing phone or business_name sets status='pending_reverification' and is_verified=false.
- (decision) AD: Supabase Free Tier lifecycle protocol. Scheduled GET /api/health running SELECT 1 every 3 days prevents 7-day inactivity pause. Scheduled pg_dump GitHub Action provides free-period backups. Decision rule: Upgrade to Supabase Pro (/mo) before public Negombo launch.
- (decision) AD: Image and hosting strategy. Images stored in Supabase Storage 'provider-photos'. Next.js Image component handles responsive WebP delivery. Vercel Hobby permits non-commercial pilot up to 5,000 transformations/mo; upgrade to Vercel Pro or Docker container (Railway/VPS) upon commercialization.
- (constraint) Multi-developer ownership: Route groups (public), (provider), (admin) are developed in parallel. Shared code (lib/, components/ui/), DB migrations, and RLS policies must have single-owner serialized changes.
